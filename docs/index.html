Download v0.1.0 Run in GitHub Actions

Install

One Python package. One command.

python -m pip install code-audit-community
code-audit-community path/to/project
code-audit-community path/to/project --format json --output report.json

Local by default

The scanner reads files locally and does not upload source code, paths, or reports.

Useful in CI

Return exit code 1 when a high-risk finding is present, or export JSON for another step.

Honest boundary

Findings are review candidates. A clean scan does not prove that code is safe.

Community rules

Small, readable, and intentionally limited.

  • sql-concatString-built SQL
  • pickle-loadsUnsafe deserialization
  • eval-exec-subprocessDynamic execution sinks
  • js-command-execJavaScript command execution
  • raw-html-reflectUnescaped HTML reflection
